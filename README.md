# Mowan-Energy-Box 魔丸正能量盲盒
每一次开启，都是宇宙给你的悄悄话。
一个基于积极心理学的随机能量标语盲盒。点击盲盒，抽取一句温暖的心理暗示，支持音效、复制、生成分享卡片，帮助你将正能量传递给更多人。

🌟 功能特性

🎁 盲盒抽签：点击盲盒或按钮，随机抽取一条积极心理暗示标语。

🔊 沉浸音效：开启声、粒子爆裂声、复制成功音效，全部由 Web Audio API 实时合成，无需外部音频文件。

📋 一键复制：点击结果卡片即可复制标语到剪贴板。

🖼️ 分享卡片：生成包含标语、品牌名、二维码的分享图（750×1000），方便在社交平台传播。

❤️ 收藏功能：收藏喜欢的标语，数据保存在浏览器本地。

📊 统计面板：记录抽签次数、标语池数量、收藏数量。

🌌 视觉氛围：星空背景、光晕粒子、盲盒摇晃、卡片弹入等动画效果。

🔒 纯前端实现：无需后端，部署简单，可直接托管于 GitHub Pages、Vercel、Netlify 等。
